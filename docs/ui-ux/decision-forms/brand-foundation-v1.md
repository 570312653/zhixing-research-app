# 品牌视觉基础集中决策表 v1

> 用途：集中确认“知行”个人 Android 客户端的品牌方向、App 图标、启动页和统一设计 Token。  
> 当前阶段：只确定正式视觉规范与未来工程参数，不初始化 Android 工程、不生成生产 APK。  
> 确认日期：2026-08-03。

## 一、不可变边界

| 项目 | 当前规则 |
|---|---|
| 产品定位 | 个人市场研究工具，专业、克制、可信、阅读优先，不营造实时交易终端感 |
| 现有成果 | 不改变九个已确认页面的信息结构、导航、内容顺序和交互语义 |
| 主题范围 | 首版只实现浅色主题；深色模式不进入第一工程切片 |
| 状态表达 | 成功、观察、风险和信息状态必须同时使用颜色、文字与图标 |
| 安全边界 | 图标、启动页、预览和未来 APK 均不得包含密钥、真实数据、真实服务端地址或动态任务内容 |

## 三、确认结果

- 用户确认：第 1～29 项全部采用推荐方案 A。
- 正式视觉方向为“深海蓝研究院”。
- 后续页面实现只能统一视觉 Token，不得借此改动已经确认的信息架构和交互。
- 如果未来需要深色模式、重新设计图标或改变状态色，必须新建补充决策表，不改写本次历史结论。

4. 新问题进入补充决策表，不重新询问已经确认的问题。
