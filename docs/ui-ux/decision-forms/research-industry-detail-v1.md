# 行业详情页决策表 v1

> 用途：集中确认“研究 → 行业 → 行业详情”页面的内容、状态和交互。  
> 当前仅进行 UI/UX 需求确认，不涉及客户端代码或真实数据接入。

## 一、已经确认，不再重复讨论

| 项目 | 已确认结论 |
|---|---|
| 页面信息顺序 | 当前趋势 → 关键证据与对比 → 趋势历史 → 关联关注标的 → 专项行业报告 |
| 趋势历史 | 按日期展示“状态 + 证据”的时间线，不使用没有明确公式支持的综合分数折线图 |
| 关联关注标的范围 | 同时展示当前关注标的，以及近期新增、关注原因更新、移出记录 |
| 专项报告归档 | 报告只保存一份，通过行业标签同时出现在报告库和对应行业详情页 |

1. 把你的选择和补充意见写入本表，形成最终决策记录。

4. 你确认预览后，保存正式 HTML 页面稿、PNG 快照，并登记到 UI/UX 页面索引。
