## 1. 产品与视觉目标

- 仅供项目所有者本人使用的个人市场研究工具。
- Android APK 为主要客户端，推荐使用 Capacitor 封装 Web 界面。
- 阅读优先、浅色、专业克制；不做行情大屏、社交、多人管理或交易入口。
- 报告和研究信息必须显示版本、数据截至时间、生成/同步时间及必要风险提示。
- 当前工程切片只允许固定样例，不包含真实数据、密钥或服务端地址。

## 3. 主导航与页面关系

```text
底部主导航
├─ 今日
│  ├─ 日常报告卡 → 报告详情
│  └─ 周期报告卡 → 报告详情
├─ 报告库
│  ├─ 搜索 / 类型 / 日期 / 行业 / 主题筛选
│  └─ 报告卡 → 报告详情
├─ 研究
│  ├─ 总览
│  ├─ 行业 → 行业列表 → 行业详情
│  │                       ├─ 当前标的 → 标的详情
│  │                       └─ 关联报告 → 报告详情
│  └─ 标的池 → 标的详情
│              ├─ 关联行业 → 行业详情
│              └─ 关联报告 → 报告详情
└─ 我的
   ├─ 今日任务与失败恢复
   ├─ 本机 PDF / 离线缓存
   ├─ 运行诊断
   └─ 版本、设备与访问
```

### 导航规则

- 底部四个一级入口始终保持相同顺序，不根据页面或状态动态变化。
- 详情页保留明确返回路径；行业与标的之间允许双向进入。
- 周期报告不新增一级入口，统一进入报告详情并永久归档到报告库。
- “我的”只承担所有者操作、任务、缓存、诊断和版本，不恢复旧的订阅或成员管理。

## 4. 页面职责与数据依赖

| 页面 | 页面只负责 | 不应承担 |
|---|---|---|
| 今日 | 当日阅读入口、摘要、四类日常卡、动态周期报告 | 全量任务监控、历史检索、报告编辑 |
| 报告库 | 本地/未来云端报告索引、搜索与组合筛选 | 全文编辑、任务重试 |
| 报告详情 | 受控 HTML 阅读、版本历史、PDF 下载入口 | Prompt、数据源配置、任意脚本渲染 |
| 研究总览 | 行业和标的池的当期变化摘要 | 实时行情大屏、综合评分编造 |
| 行业列表/详情 | 行业趋势、证据、反向证据、历史、关联标的与报告 | 手动修改趋势、荐股、交易 |
| 标的池/详情 | 完整快照、派生变化、关注依据、风险与追溯 | 从报告正文猜测标的、手动编辑状态 |
| 我的 | 同步、失败重试、缓存、诊断、版本与访问入口 | 密钥、原始响应、后台完整日志 |

## 5. 通用状态组件

正式视觉参考：`screens/cross-page-states.html`；决策依据：`decision-forms/cross-page-states-v1.md`。

| 组件建议 | 范围 | 关键规则 |
|---|---|---|
| `PageSkeleton` | 页面级 | 保留标题和导航；约 300ms 后显示，超过 10s提示较慢 |
| `SectionSkeleton` | 区块级 | 形状与最终内容一致，不阻断其他已加载区块 |
| `ContextualEmptyState` | 页面/区块级 | 区分未到时间、当天无内容、筛选无结果和暂无历史 |
| `BlockingFailureState` | 页面级 | 仅在没有任何可用内容时使用；错误信息脱敏 |
| `InlineFailureNotice` | 区块/操作级 | 保留其他内容，反馈放在失败操作附近 |
| `OfflineBanner` | 全局非阻断 | 有缓存继续阅读，显示最后同步时间，禁用在线操作 |
| `StaleContentNotice` | 页面/区块级 | 同步失败但有旧内容时使用，不把旧内容伪装成最新 |
| `ActionFeedback` | 操作级 | 进行中防重复点击；成功轻提示；失败原位说明 |

状态优先级：所有者访问/安全阻断 ＞ 无内容失败 ＞ 离线无缓存 ＞ 加载 ＞ 空内容。离线有缓存和失败有旧内容可以与正常阅读叠加。

## 6. 共享 UI 模块建议

- `AppShell`：安全区、标题栏、底部导航、网络状态承载。
- `ReportCard`：类型、标题、日期、版本、数据时间、阅读与任务状态。
- `ReportHtmlRenderer`：受控 HTML 白名单渲染，不执行脚本或不受控样式。
- `FilterBar`：报告库、行业、标的池的搜索与筛选组合。
- `EvidenceCard`：支持证据、反向证据、数据时间和类别。
- `RiskCard`：与正向判断同等可见的风险说明。
- `Timeline`：行业与标的的可追溯历史。
- `TaskStatusCard`：任务摘要、脱敏错误、确认后重试。
- `VersionBadge`、`ReadStateBadge`、`FreshnessBadge`：统一版本、阅读与时效语义。

模块名称是建议，实施时可调整；边界和复用关系不得被拆成页面内重复实现。

## 7. 固定样例与未来接口边界

- 第一工程切片的唯一数据实现是本地固定夹具仓库。
- `FutureApiClient` 只能定义类型，不得访问网络、硬编码测试地址或携带真实 Token。
- 样例报告必须通过既有报告契约和受控 HTML 校验后才能进入夹具。
- 标的池必须使用独立完整快照夹具，不得从报告正文推断。
- PDF 按钮在无真实文件时显示不可用，不生成空 PDF 或伪下载。
- 所有“刷新、同步、重试、检查更新”在离线切片中必须禁用或明确标注未接入，不得模拟成功。

## 8. 工程验收清单

### 8.1 视觉与适配

- [ ] 390px 宽度无横向滚动，Android 安全区不遮挡标题和底部导航。
- [ ] 页面层级、卡片顺序、浅色视觉和阅读密度与正式 HTML/PNG 一致。
- [ ] 字号、点击区域和对比度适合手机长期阅读；状态不只依赖颜色。
- [ ] 支持系统“减少动态效果”，骨架与页面切换没有持续强闪烁。

### 8.2 导航与交互

- [ ] 四个底部入口顺序固定，返回路径和深链可预测。
- [ ] 报告、行业和标的的交叉入口均进入正确详情页。
- [ ] 搜索、筛选、清除筛选和展开历史的操作结果可见。
- [ ] 首版不存在分享、交易、成员、订阅、手动编辑趋势或标的状态入口。

### 8.3 内容与状态

- [ ] 报告卡和详情展示类型、日期、版本、数据截至时间和生成/同步时间。
- [ ] 今日四个日常位置固定；周期报告有内容才出现。
- [ ] 加载、空、失败、离线、旧内容叠加场景均可通过固定夹具独立复现。
- [ ] 无可用内容时失败关闭；有最后成功内容时保留阅读并显式标注过期。
- [ ] 错误码和诊断摘要脱敏，界面与日志均不出现密钥或完整原始响应。

### 8.4 安全与工程边界

- [ ] APK、源码、构建产物、截图和日志中不存在真实密钥、真实服务端地址或敏感数据。
- [ ] 报告 HTML 经过白名单净化，不执行脚本、事件属性或任意远程资源。
- [ ] 客户端无法修改报告、行业判断、标的池快照或生成 Prompt。
- [ ] 未来重试操作使用服务端幂等标识，客户端不无限自动重试。
- [ ] 现有报告引擎回归测试保持通过。
