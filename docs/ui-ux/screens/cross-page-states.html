范围 页面 / 区块 / 操作原则 旧内容可读但不伪装恢复 在线且可重试才显示按钮
① 局部问题局部呈现筛选失败、PDF 下载失败等不替换整页；只有没有任何可用内容时才进入页面级失败。
② 空内容不等于失败区分未到时间、当天没有、筛选无结果和暂无历史，并给出与原因匹配的下一步。
③ 离线优先保留阅读缓存内容继续可读，明确最后同步时间；刷新、重试和未缓存下载暂时禁用。
④ 错误信息必须脱敏只显示错误码、发生时间和恢复动作，不展示原始响应、密钥或后台完整日志。

  • 危险操作仍需二次确认。
