# 核心关注标的详情页决策表 v1

> 用途：集中确认从标的池卡片进入的“标的详情页”信息结构、历史追溯和异常状态。  
> 同步提供一份按推荐项生成的临时 UI 预览，便于对照判断；预览不代表选择已经锁定。

## 一、不可变的产品边界

| 项目 | 当前规则 |
|---|---|
| 页面定位 | 解释一个标的为什么进入研究观察、当前风险和历史变化，不构成投资建议 |
| 市场范围 | 第一版只包含 A 股标的 |
| 数据来源 | 展示报告引擎完整快照及应用派生的变化历史，不从报告正文猜测标的状态 |
| 操作权限 | 页面只读，不允许手动修改关注原因、状态或移出记录 |
| 禁止内容 | 不展示买卖点、目标价、仓位、止损、收益承诺或个人持仓建议 |
| 实时能力 | 第一版不是实时行情终端，当前也没有接入真实 `watchlist_snapshot` |

## 三、推荐预览所采用的默认结论

临时预览使用第 1～12 项的推荐方案 A：阅读优先顺序、完整身份、突出关注结论、正反证据卡、独立风险、可追溯时间线、移出状态留痕、行业双向联动、最近 3 份报告、不展示行情与收益、显式过期提示及只读操作。

## 四、确认后的处理方式

1. 将最终选择写回本表。
2. 根据选择和补充意见修订 UI 预览；如产生新边界，另建补充决策表。
3. 预览确认后保存正式 HTML、完整 PNG，并登记到 UI/UX 页面索引。
4. 下一页进入“我的 / 个人操作页”，继续使用相同流程。

- 用户确认：第 1～12 项全部采用推荐方案 A。
