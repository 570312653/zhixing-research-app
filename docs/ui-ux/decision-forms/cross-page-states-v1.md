# “跨页面状态规范”集中决策表 v1

> 用途：统一“知行”客户端正常、加载、空内容、失败、离线五类状态的视觉、文案和操作语义。  
> 范围：今日报告、报告库、报告详情、研究、标的池与“我的”等已确认页面。  
> 当前阶段：只确定 UI/UX 与未来接口语义，不实现客户端状态管理、云端接口或真实重试。

## 一、不可变边界

| 项目 | 当前规则 |
|---|---|
| 数据真实性 | 不得用占位数据、旧数据或模型补写内容伪装成最新成功结果 |
| 阅读连续性 | 已有最后成功内容时尽量保留可读，并明确标注“可能已过期”和最后同步时间 |
| 失败关闭 | 没有可用内容时显示明确失败或不可用状态，不回退到虚构内容 |
| 离线边界 | 已缓存内容可读；刷新、重试、更新和未缓存下载等在线操作禁用 |
| 错误信息 | 用户端只展示脱敏错误码、时间和可执行动作，不展示密钥、原始响应或完整日志 |
| 当前切片 | 离线固定样例阶段不得声称真实网络、云端任务、认证或重试能力已经上线 |

## 三、推荐方案的统一状态模型

推荐第 1～14 项全部采用 A，并按以下逻辑判断：

```text
先判断是否存在安全或所有者访问阻断
  └─ 是：显示阻断页，不展示受保护内容
  └─ 否：判断是否有可用内容
       ├─ 有最新内容：正常展示
       ├─ 有旧内容 + 离线/同步失败：继续阅读 + 非阻断提示
       └─ 无可用内容：
            ├─ 正在读取：加载骨架
            ├─ 合法地没有内容：原因明确的空状态
            └─ 读取失败或离线无缓存：页面级失败/离线不可用
```

## 四、推荐预览包含的场景

- 正常：今日报告内容正常、时间与版本清晰。
- 加载：页面框架稳定，内容区骨架，不遮挡底部导航。
- 空内容：展示“尚未到生成时间”，并提供查看最近报告的真实入口。
- 失败：无可用内容时显示脱敏错误与手动重试。
- 离线：缓存内容继续可读，顶部明确离线且禁用在线操作。
- 局部异常：同步失败时保留旧内容并标注可能过期。

## 五、确认结果（2026-08-02）

用户确认“都按推荐项进行”，第 1～14 项全部采用 A。该结论作为所有已确认客户端页面的通用状态规范；后续实现若改变缓存、同步、重试、错误展示或身份阻断机制，必须先更新本表并重新确认。

## 六、确认后的处理方式

1. 将最终选择写回本表。
2. 根据选择修订跨页面状态预览；新问题进入补充决策表，不逐条打断确认。
3. 用户确认后生成正式 HTML、PNG，并登记到 UI/UX 索引。
4. 同步更新客户端总设计中的状态模型、验收标准和页面数量表述。
5. 完成 UI/UX 收口后，再编写工程实施计划；本轮不直接开始实现。
