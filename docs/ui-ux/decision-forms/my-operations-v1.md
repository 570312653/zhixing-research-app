# “我的 / 个人操作页”决策表 v1

> 用途：集中确认底部导航“我的”页面的任务状态、刷新、离线缓存、诊断和版本更新入口。  
> 同步提供一份按推荐项生成的临时 UI 预览，便于对照判断；预览不代表选择已经锁定。

## 一、不可变的产品边界

| 项目 | 当前规则 |
|---|---|
| 用户范围 | 第一版仅项目所有者本人使用，不提供注册、邀请、成员或运营管理 |
| 页面定位 | 个人操作、任务状态、离线缓存、诊断和版本入口，不是社交个人主页 |
| 任务权限 | 可请求刷新和重试失败任务，但不能在客户端编辑报告、Prompt 或数据源 |
| 安全边界 | 不展示 Token、API Key、原始敏感响应、服务端环境变量或完整后台日志 |
| 当前阶段 | 仍是离线固定样例；认证、云端任务、私有归档和正式更新服务尚未接入 |

## 二、本轮待确认

可以回复“全部按推荐项”，也可以按 `1A、2B、3A……` 说明选择，并在编号后补充意见。

## 三、推荐预览所采用的默认结论

临时预览使用第 1～12 项的推荐方案 A：个人运行面板、顶部运行状态、今日任务摘要、受控重试、同步与生成分离、离线可读、缓存管理、脱敏诊断、私有 APK 更新入口、访问状态预留、不恢复通知订阅、危险操作二次确认。

## 四、确认结果（2026-08-02）

用户确认“全部按照推荐”，第 1～12 项全部采用 A。该结论作为“我的 / 个人操作页”正式页面规范；后续实现若改变任务权限、认证、离线缓存或 APK 更新机制，必须先更新本表并重新确认。

## 五、确认后的处理方式

1. 将最终选择写回本表。
2. 根据选择和补充意见修订 UI 预览；如产生新边界，另建补充决策表。
3. 预览确认后保存正式 HTML、完整 PNG，并登记到 UI/UX 页面索引。
4. 下一批集中处理正常、加载、空、失败、离线五类跨页面状态。
