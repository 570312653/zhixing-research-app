页面使用顺序

  1. 先通过四项摘要理解快照的整体变化。
  2. 默认阅读当前关注标的，最近发生变化的标的排在前面。
  3. 使用搜索、状态和行业筛选缩小范围。
  4. 点击行业标签进入行业详情，点击卡片主体进入标的详情。
  5. 需要追溯变化时切换到“变更记录”。

过期与失败状态

如果新快照获取失败，保留最后一次成功快照，同时在顶部明确显示“数据可能已过期”、最后成功时间和刷新入口；不会清空历史，也不会静默伪装成最新数据。
