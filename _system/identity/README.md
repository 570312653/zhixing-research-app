# Identity

## Durable Context

- Project owner / user: AI 爱好者，使用 Codex 开发实用的小工具。
- Working style: 重要工程决策先说明依据、影响范围和验证方式；写入前保持可审查、可回滚。
- Domain background: 正在搭建非个人化市场研究报告生成、归档与阅读应用。
- Long-lived preferences: 项目状态和存档保留在当前项目目录，不污染全局个人工作系统。

## Communication Preferences

- Preferred language: 简体中文。
- Tone: 口语化、清晰、直接。
- Detail level: 关键判断需要解释，普通结果保持简洁。

## Stable Constraints

- Do: 完成任务后列出生成或修改的文件及完整路径。
- Avoid: 未经授权扩大项目范围、接入真实数据或外部服务、把项目进度写入全局工作系统。

## Update Rule

Read this file when user preference, domain background, or long-term context matters.
Only record preferences confirmed by the user; ask before changing stable identity or preferences.
