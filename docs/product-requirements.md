# 知行：个人 Android 客户端产品需求

> 状态：已确认的产品方向；当前仍处于离线固定样例原型阶段。  
> 最后更新：2026-08-01

## 产品定义

知行是一款仅供项目所有者本人使用的个人市场研究报告工具。它由可信云端的报告引擎定时生成非个人化市场研究内容，再由 Android APK 提供移动端阅读、归档、分类和个人操作体验。

它不是自动交易、行情终端、个性化荐股或收益承诺工具。所有报告固定展示：**仅供信息参考，不构成投资建议。**

## 用户与访问范围

- 仅允许一个所有者账户访问，不开放注册、邀请、多人阅读、对外分享或公开链接。
- Android APK 是第一版主要入口；未来可保留受保护的 Web 入口用于电脑访问，但不作为公开网站运营。
- APK 被复制不等于获得权限：服务端必须校验所有者身份，普通客户端不得持有数据源、模型或管理密钥。
- 不做收费、会员、支付、社区、评论、反馈系统、订阅偏好或运营阅读统计。

## 报告内容与节奏

| 内容 | 范围 | 目标生成完成时间 | 处理方式 |
|---|---|---:|---|
| 早盘扫描 | 美股、期货等外围信息，为 A 股开盘提供背景 | A 股交易日 08:45 | 自动生成，失败关闭 |
| 午盘复盘 | A 股上午收盘后的行情走势、异动与前序判断验证 | A 股交易日午间 | 自动生成，失败关闭 |
| 每日复盘 | 仅 A 股 | A 股交易日 17:30 | 自动生成，失败关闭 |
| 行业跟踪 | 关注行业的趋势、研究与观察标的整理 | A 股交易日 20:00 | 自动生成，失败关闭 |
| 节假日资讯摘要 | 连续休市期间的价值新闻与信息 | 连续休市最后一天 20:00 | 自动生成，失败关闭 |
| 月末复盘 | 月度市场与行业研究复盘 | 月末规则待后续细化 | 自动生成，失败关闭 |

交易日必须按 A 股实际交易日历判断。数据、交易日历、来源证据、数据截至时间或合规校验不足时，系统不得生成或发布报告。

## Android APK 客户端范围

1. **今日报告**：显示当天的早盘、午盘、复盘、行业跟踪及其生成/延迟状态。
2. **报告库**：按日期、报告类型、行业和主题检索历史报告。
3. **报告详情**：阅读 HTML 报告、查看版本与数据截至时间、下载 PDF、阅读风险提示。
4. **产业与标的池**：查看行业跟踪、核心关注标的及新增、持续关注、移出历史。
5. **个人操作页**：查看任务状态、请求重试失败任务、刷新内容、查看客户端版本。

不做实时行情大屏、自动交易、个性化仓位分析、投资指令或 iOS 客户端。

## 安装与更新

- 通过 HTTPS 下载页生成二维码，所有者扫码下载并安装已签名的 Android APK。
- Android 首次安装可能要求用户在系统中允许该下载来源安装应用。
- 新版本必须使用同一签名证书并提高版本号，用户从同一下载页下载后覆盖安装。
- 二维码不得包含报告正文、账户令牌、数据源令牌或管理凭证。

## 报告与归档规则

- 同一份报告从 `v1.0` 开始，修订后依次为 `v1.1`、`v1.2`；历史版本永久保留。
- 报告库默认展示最新版本，详情可以查看历史版本。
- HTML 是默认阅读格式；PDF 由同一份已校验 HTML 导出。PDF 导出失败不能覆盖已经归档的 HTML 报告。
- 核心关注标的池是可追溯的研究观察清单，不使用“荐股池”或“推荐池”表述。
- 报告不得输出买卖点、仓位、止损、收益承诺或针对个人资金/持仓的建议。

## 数据源与运行边界

- iFind 是后续个人主数据候选，但尚未接入。必须先单独验证其适合云端定时调用的技术方式、字段、数据时间、配额、证据留存和失败语义。
- 数据源、模型和管理凭证只允许存放在未来可信云端的受控环境变量中，绝不进入 APK、前端、仓库、日志、文档或二维码。
- Codex 用于开发、测试和维护，不是生产定时器。正式调度由 Vercel Cron 或同等可信云端运行时承担。
- Coze 的全部 Agent、Skill、Calendar、Webhook 和 API POC 仅为历史审计资料，不能恢复为正式生成路径。

## 成功标准

- Android APK 可在真机完成安装、打开、身份验证、查看固定样例报告、检索归档和下载测试 PDF。
- 报告引擎在固定样例下保持失败关闭：输入证据不足时不产出伪市场报告。
- 报告视觉在手机宽度下没有横向溢出，且与桌面/A4 HTML 语义一致。
- 后续真实数据和云端调度接入前，必须分别通过数据适配器、凭证隔离、任务幂等和故障恢复验收。

## 当前阶段边界

- 当前只允许离线固定样例、无密钥、无真实数据、无模型、无云端部署、无真实 PDF、无日程和无用户系统的原型工作。
- 真实数据、iFind 凭证、云端运行时、私有存储、Android 签名与下载页均属于后续独立、确认后才可开展的阶段。
