# 知行报告引擎：个人 Android APK 架构

> 状态：已确认的目标架构；当前仅完成离线固定样例原型，尚未部署或接入真实数据。  
> 最后更新：2026-08-01

## 1. 架构决策

正式路线由“多人 Web 报告订阅应用”调整为“单一所有者的 Android APK + 可信云端报告引擎”。Android APK 是可安装的个人客户端；报告引擎是独立的后台系统。Codex 仅用于开发、测试与维护，不是生产运行时或定时器。

```text
Android APK（Capacitor）
  → 受保护的应用 API
    → 私有报告归档 / 任务状态
    → 知行报告引擎
      → 交易日历适配器 + 数据源适配器
      → 证据标准化与校验
      → 模型仅依据已验证证据生成
      → JSON / 受控 HTML / 合规校验
      → HTML 归档 → Playwright + Chromium 导出 PDF
```

未来的可信云端运行时（Vercel Cron 或同等服务）负责触发报告引擎。客户端只请求已归档报告和受限的个人操作接口，不能直接调用数据源、模型或管理接口。

## 2. 客户端与权限边界

### Android APK

- 推荐技术：Capacitor 原生外壳承载 Web 界面；复用已验证的响应式 HTML 报告样式。
- 交付：由 HTTPS 下载页提供已签名 APK，二维码只链接下载页。
- 更新：保持同一签名证书，提升版本号后覆盖安装。
- 安全：APK 可被复制，不能将安装包本身当作身份凭证；不得内置密钥、固定管理员令牌或数据源 Token。

### 单一所有者访问

- 应用 API 必须验证单一所有者身份并使用短期会话；身份验证方案在客户端设计阶段确认。
- 报告、PDF、任务状态和手动重试接口均只允许所有者账户访问。
- 不实现注册、邀请、角色、订阅、公开链接、多人 RLS 或运营数据分析。

## 3. 报告引擎边界

- 只支持：`morning_scan`、`midday_review`、`daily_review`、`industry_tracking`、`holiday_digest`、`month_end_review`、`industry_research`。
- 报告是非个人化市场研究：不消费用户持仓、账户、偏好或资金信息；不输出买卖、仓位、止损、收益承诺或个性化建议。
- 交易日、数据源、数据截至时间、来源证据或合规校验任一不足，必须返回结构化错误并失败关闭。
- HTML 是默认阅读格式。只有业务校验与 HTML 校验均通过时，才可导出 PDF；PDF 失败不得伪造成功或抹除 HTML 报告。
- 报告版本、原始任务标识、数据截至时间、生成时间和内部证据元数据必须可追溯。

## 4. 数据源候选与适配器

iFind 是用户选择的后续个人主数据候选，但本文件不把它视为已接通能力。真实接入前必须完成独立的适配器契约，至少包括：

- 交易日历和各类报告所需字段；
- 调用方式是否适合可信云端的自动任务；
- 数据时间、时区、调用配额与超时；
- 结构化证据、来源标识、原始数据版本与可审计元数据；
- 错误分类、退避、幂等与数据缺失时的失败关闭语义；
- 凭证仅通过云端受控环境变量注入，不出现在 APK、前端、日志或测试夹具。

在这份适配器契约获确认前，不创建 iFind 密钥、不接入网络、不生成真实市场报告。

## 5. 分段实施与验收

### A. 已完成：离线固定样例报告原型

`morning_scan`、`midday_review`、`daily_review` 和 `industry_tracking` 已使用本地固定夹具完成严格 JSON/受控 HTML 与响应式视觉验证。它们不代表真实数据、真实交易日或正式 PDF 导出。

### B. 下一步：个人 Android 客户端设计与离线 APK 外壳

先用固定样例完成客户端信息架构、单一所有者 API 边界和 Capacitor APK 真机安装验证。不接入真实数据、凭证、云端日程或生产存储。

### C. 后续：数据适配器与可信云端

数据适配器契约、凭证隔离、私有归档、云端调度和正式 PDF 导出各自单独设计、确认和验证。任何一个前置条件未满足，不得启用自动生成。

## 6. 不可突破的边界

- 不恢复 Coze 作为正式报告生成路径；历史 Coze POC 只保留审计价值。
- 不接入真实数据、模型、网络、环境变量、云端部署、日程或 iFind 凭证，除非用户完成相应的后续独立确认。
- 不在客户端或下载二维码中保存敏感信息。
- 不因数据不足而编造市场事实、来源或结论。
