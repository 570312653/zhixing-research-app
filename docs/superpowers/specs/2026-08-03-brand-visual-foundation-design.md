# 知行客户端品牌视觉基础设计

> 状态：用户已于 2026-08-03 确认全部推荐项并通过书面规格复核。  
> 范围：App 图标、Android 启动页和统一设计 Token；不初始化客户端工程或生产 APK。

## 1. 目标

在不改变九个已确认页面的信息结构、导航和交互的前提下，为“知行”个人 Android 客户端建立单一、可实现、可验收的品牌视觉基础。视觉气质为“深海蓝研究院”：专业、克制、可信、阅读优先，不模拟交易终端或行情大屏。

## 2. App 图标

- 核心图形为“折页与路径”：打开的书页代表研究与阅读，中间向前的路径代表“知而后行”。
- 不使用 K 线、涨跌箭头、金币、牛熊或荐股符号。
- 使用 Android 自适应图标：前景图形和背景色分离，确保圆形、圆角方形、水滴形遮罩下均不裁切核心图形。
- 背景使用 `brand-primary`，主图形使用白色，允许少量 `brand-accent` 高光。
- 图标内不放完整“知行”、单个汉字或字母，避免小尺寸糊字和字体依赖。
- 交付形式：1024×1024 母版、前景层 SVG、背景色、单色 SVG；工程阶段再生成 Android mipmap 资源。

正式矢量参考：[app-icon-master.svg](../../ui-ux/brand/app-icon-master.svg)。

## 3. Android 启动页

- 浅灰白 `surface-page` 背景，居中展示 App 图标、“知行”和“个人市场研究”。
- 不显示同步进度、最新报告日期、任务完成度或其他动态内容。
- 允许最长 220ms 的透明度淡入；系统启用“减少动态效果”时直接显示静态内容。
- Android 12+ 使用系统 SplashScreen 能力；品牌图标位于安全区内，进入 App 后自然衔接浅色页面。
- 启动页不承担认证、同步和错误反馈；这些状态由 App 页面处理。

正式静态参考：[splash-screen-preview.svg](../../ui-ux/brand/splash-screen-preview.svg)。

## 4. 颜色 Token

| Token | 值 | 用途 |
|---|---|---|
| `brand-primary` | `#1E3A8A` | 主按钮、激活导航、重点容器、品牌图标背景 |
| `brand-ink` | `#102B44` | 页面标题、最高层级正文、深色品牌文字 |
| `brand-accent` | `#2F6C9E` | 链接、轻强调、图形高光 |
| `text-primary` | `#1F2937` | 正文主文字 |
| `text-muted` | `#6B7280` | 元数据、说明和次级文字 |
| `text-subtle` | `#98A2B3` | 弱提示，不用于关键正文 |
| `surface-page` | `#F4F7FA` | App 页面背景与启动页背景 |
| `surface-card` | `#FFFFFF` | 卡片和主要阅读容器 |
| `surface-subtle` | `#F3F4F6` | 标签、筛选、斑马行和弱分区 |
| `border-default` | `#DDE7ED` | 默认 1px 描边 |
| `signal-positive` | `#15803D` | 成功、已验证；必须配文字和图标 |
| `signal-watch` | `#B45309` | 观察、待验证；必须配文字和图标 |
| `signal-risk` | `#B91C1C` | 风险、失败；必须配文字和图标 |
| `signal-info` | `#2F6C9E` | 普通信息和链接状态 |

不得继续以 `#173F6B`、`#143B61`、`#2876A5` 等旧页面值作为新的主 Token。后续工程实现统一替换，但正式历史预览无需批量重写。

## 5. 字体、字号与行高

- 字体栈：`PingFang SC`, `Microsoft YaHei`, `Noto Sans CJK SC`, `system-ui`, `sans-serif`。
- 不依赖在线字体；离线 APK 和未来 PDF 环境必须有可用回退。
- 字号层级：12、14、16、20、24、30px。
- 正文建议 14～16px、行高 1.65～1.8；元数据最小 12px；关键操作与标题不得用弱文字颜色。

## 6. 空间、圆角与阴影

- 间距：4、8、12、16、24、32、40px。
- 圆角：8px 用于小标签/控件，12px 用于普通卡片，16px 用于重点容器，24px 用于大容器；胶囊使用 999px。
- 描边：默认 `1px solid #DDE7ED`。
- 阴影仅两级：
  - 卡片轻阴影：`0 2px 8px rgba(16, 43, 68, 0.05)`；
  - 浮层中阴影：`0 12px 30px rgba(16, 43, 68, 0.12)`。
- 不使用大面积高饱和渐变、连续强阴影或后台仪表盘式悬浮面板。

## 7. 动效

- `motion-fast`：160ms，用于轻量状态反馈。
- `motion-normal`：220ms，用于页面或容器淡入。
- 位移不超过 4px，主要使用透明度和轻位移。
- 不使用持续闪烁、弹跳和装饰性加载动画；尊重系统“减少动态效果”。

## 8. 工程交付边界

- Token 后续以单一源维护，并生成 CSS Custom Properties 与 TypeScript 常量。
- 第一工程切片只使用本地固定样例，不接入真实数据、密钥、网络、云端调度或认证。
- 视觉统一不得改变页面信息架构、导航顺序、报告状态语义和失败关闭规则。
- 当前规范是工程输入，不表示 Android 工程、图标 mipmap、系统 SplashScreen 配置或 APK 已经完成。

## 9. 验收

1. 图标在 48、72、96、192px 下保持清楚，常见 Android 遮罩不裁切核心图形。
2. 启动页在常见 Android 长宽比及浅色系统导航区域下无明显跳色或裁切。
3. 390px 页面无横向滚动；正文和状态对比度适合长期阅读。
4. 状态不只依赖颜色，所有关键状态都有文字和图标。
5. 页面工程使用统一 Token，不再新增任意蓝色、圆角、阴影或字体值。
6. 现有报告引擎回归保持通过；视觉收口不修改报告内容契约。
