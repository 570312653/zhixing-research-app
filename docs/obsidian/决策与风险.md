# 决策与风险

## 已确认的关键决策

1. 产品第一版改为项目所有者本人使用的 Android APK，不开放朋友注册、共享阅读、订阅或收费。
2. 客户端采用 Capacitor 混合方案；报告引擎未来运行在可信云端，Codex 不需要持续在线。
3. 当前开发仍只允许离线固定样例原型；数据不足、来源不明或校验失败时必须失败关闭。
4. 内容定位为非个人化市场研究，不提供个性化持仓建议、买卖指令或收益承诺。
5. 报告引擎已实现 `morning_scan`、`midday_review`、`daily_review`、`industry_tracking` 四类固定样例，最近一次完整本地回归为 124/124。
6. iFind 只是后续个人主数据源候选；尚未验证云端调用、接口字段、时效、配额、凭证或真实数据。

## 当前主要风险与待办

- 客户端信息架构、主导航、页面布局、状态反馈和关键交互仍未形成用户确认的完整 UI/UX 规格。
- 当前目录尚未初始化 Git；历史测试目录中存在环境文件候选，初始化前必须先完成敏感文件清理方案和忽略规则。
- 本机尚未准备 JDK、Android SDK、ADB 与 Gradle 等 Android 构建工具，不能声称可生成 APK。
- 真实交易日历、真实数据来源、模型供应商、应用 API、云端调度和私有归档均未实现。
- HTML 到正式 PDF 的渲染、存储和下载流程尚未配置；现有 A4 样式不等于正式 PDF 能力。

> [!danger] 不可跨越的边界
> 不把候选数据源描述为已接入，不把固定夹具视为真实市场结论，不在 APK 或前端中保存数据源/模型密钥，也不在 UI/UX 确认前直接初始化 Android 工程。
