# 报告模板与研究

## 报告类型

| 类型 | 当前状态 | 说明 |
| --- | --- | --- |
| 早盘扫描 `morning_scan` | 已有离线固定样例 | 提供外围市场背景，不构成交易建议。 |
| 午间复盘 `midday_review` | 已有离线固定样例 | 包含对早盘和前一日复盘判断的可追溯验证。 |
| 每日复盘 `daily_review` | 待实现 | 需先补固定夹具、失败样例和测试。 |

| 月末复盘 `month_end_review` | 待实现 | 需先补固定夹具、失败样例和测试。 |
| 产业研究 `industry_research` | 待实现 | 需先补固定夹具、失败样例和测试。 |

## 输出原则

- 所有内容必须是非个人化市场研究。
- 每份报告必须具有可追溯来源、数据截至时间、生成时间和版本。
- HTML 先经过白名单与内容合规校验；PDF 是后续独立能力，不得伪造导出成功。
- 数据或来源不足时失败关闭，不补写、不编造。
