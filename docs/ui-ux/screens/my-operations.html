推荐方案映射

页面操作逻辑

  1. 先确认当前运行模式、访问状态和最后同步时间。
  2. 查看今日四类任务是否完整，失败项才展开恢复入口。
  3. “刷新内容”只同步索引与状态，不重新生成报告。
  4. 本机 PDF 和缓存可管理，但不能删除云端归档。
  5. 版本、诊断和访问入口集中放在页面底部。

离线与安全边界

  • 离线时已缓存报告继续可读，刷新与重试暂时禁用。
  • 诊断信息只包含脱敏错误码、时间、版本和诊断编号。
  • 首版不展示通知、订阅、成员、数据源或模型配置。
  • 清缓存、退出和锁定需要二次确认。

样例边界

当前还没有认证、云端任务或正式 APK 更新服务。页面展示的是未来接口结构和固定状态样例，不得据此声称这些能力已经上线。
